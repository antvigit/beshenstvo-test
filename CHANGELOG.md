# Changelog

## [v4.0] — 2026-09-17
### Добавлено
- **Выбор браузера в Telegram-боте**: после выбора раздела `/run` показывает
  второй шаг — 🌐 Chrome + Firefox / 🖥 Только Chrome / 🦊 Только Firefox.
  Новый workflow_dispatch input `browser` управляет матрицей job'ов через
  отдельный job `setup`, вычисляющий её динамически (`fromJson`).
- **Контейнеризация тестов**: `run-tests.yml` теперь собирает и запускает
  тесты внутри корневого `Dockerfile` (`docker run --network host`), а не
  напрямую на раннере.
- **Параллельный запуск JUnit 5**: включён (методы — параллельно в 2 потока,
  классы — последовательно; полная параллельность классов+методов перегружала
  машину и путала атрибуцию отчётов в surefire).

### Исправлено
- **Матрица браузеров в CI была нерабочей**: `System.getenv("browser")` /
  `System.getenv("grid.url")` никогда не видели `-Dbrowser=`/`-Dgrid.url=`,
  которые CI передаёт как JVM system properties, а не переменные окружения —
  вкладка «firefox» в матрице всё это время молча тестировала Chrome, а
  Selenium Grid из docker-compose не использовался вовсе. Новый
  `support/WebDriverFactory` читает их правильно и используется во всех
  тестовых классах.
- `testFullFormSubmission`: ввод даты рождения через клик по календарю не мог
  в принципе проставить дату из прошлого без навигации по месяцам/годам,
  которой в коде не было, и вдобавок падал с `ElementNotInteractableException`
  на CI. Переписан на прямой ввод цифр в маскированное поле.
- Хардкоженный `--remote-debugging-port=9222` у Chrome-сессий вызывал
  коллизии при параллельных сессиях на одном узле Selenium Grid.
- Гонка закрытия MUI-попапа в `RheumatologyPage.selectScale` — ловилась
  только в Firefox (первый раз, когда он реально тестировался).
- `RheumatologyPage.fillNumberField`: клик иногда попадал в плавающий
  MUI-лейбл вместо поля — переведён на JS-клик.
- Гонка в тесте тёмной темы на CI (другой формат `rgb()/rgba()` на Linux,
  чтение цвета до начала CSS-transition).
- Права на `target/` после Docwrite-шага на нативном Linux CI (root-owned
  файлы, в отличие от Docker Desktop for Mac, где владение мапится прозрачно)
  — добавлен `sudo chown` перед `mvn allure:report`.
- Ожидание готовности Selenium Grid никогда не срабатывало
  (`grep '"ready":true'` без пробела не матчил pretty-printed JSON хаба).

Все фиксы для Docker/параллелизма/браузеров проверены дважды: локально через
настоящий `docker compose` + Selenium Grid (для чего специально поставлены
Docker Desktop и Firefox), и вживую в GitHub Actions.

## [v3.1] — 2026-09-16
### Добавлено
- **Выбор раздела для тестирования в Telegram-боте**: `/run` теперь показывает inline-меню
  (🌐 Все разделы / 💉 Вакцинация / 🦴 Ревматология / 🩻 Рентгенология) вместо немедленного

  какой раздел выполняется.

## [v3.0] — 2026-09-16
### Добавлено
- **Покрытие раздела «Ревматология»**: новый `RheumatologyPage` (POM) и
  `RheumatologyCalculatorTest` — 14 тестов на калькуляторы `DAS28-ESR/CRP`, `CDAI`, `SDAI`
  (ревматоидный артрит), `BASDAI/ASDAS/BASFI/BASMI` (болезнь Бехтерева), `SLEDAI-2K/SELENA-SLEDAI`
  (СКВ) и `FRAX` (остеопороз). Формулы DAS28-ESR/CRP, CDAI, SDAI и BASDAI проверяются точным
  сравнением с расчётом по опубликованным клиническим формулам.
- **Покрытие поддомена «Рентгенология»**: новый `RadiologyPage` и `RadiologySiteTest`
  (smoke-проверка доступности `rad.beshenstvo.pro`).
- **Новые тесты калькулятора вакцинации**: чекбокс законного представителя, формирование PDF
  без необязательных полей ФИО/даты рождения, переключение тёмной темы, пересчёт интервалов
  графика вакцинации для произвольной даты начала.

### Исправлено
- `driver.manage().window().maximize()` в headless-режиме схлопывал viewport до мобильного
  брейкпоинта на этом хостинге, из-за чего часть верстки (например, вкладки ревматологии)
  рендерилась иначе и не находилась локаторами — maximize теперь вызывается только для видимого
  окна браузера (`-Dheadless=false`), headless-режим полагается на явный `--window-size`.
- Установка значения MUI-слайдеров через `ArrowRight` работала некорректно там, где шаг слайдера
  меньше 1 (например, 0.1 у шкал CDAI/SDAI) — значение теперь выставляется напрямую через
  нативный сеттер `value`, как при обычном перетаскивании.
- Клик по MUI-чекбоксам (визуально скрытый `input[opacity:0]` под SVG-иконкой) не проходил
  через `elementToBeClickable` — переключение чекбоксов теперь выполняется через JS-клик после
  ожидания присутствия элемента в DOM.
